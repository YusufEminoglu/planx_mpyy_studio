about=Studio for Turkish spatial planning under the Mekânsal Planlar Yapım Yönetmeliği (MPYY). Portable GeoPackage workspaces for the MPYY 1.1.7 UİP, NİP and ÇDP schemas, the local UİP and NİP drawing templates, a land-use and field-survey workspace, and a Mekânsal Strateji Planı (MSP) workspace built from the Ministry's Ek-1e catalogue with its symbols drawn after Ek-1b. Draw by plan function with the type and codes filled in; attribute forms with value lists and hard bounds; symbology from the Ministry's Ek-1e detail catalogues with the legend trimmed to the values a plan contains; level conversion (UİP to NİP and ÇDP), e-Plan GML import and CAD/NCZ transfer with schema audits; 86 Processing algorithms for plan audits and delivery: amenity standards, plan revision, density, DOP, PAİY, capacity, parking, shelter, urban transformation, plan notes, reports, print layouts and zoning certificates. The bundled symbol fonts are registered when the plugin loads, so no system font installation is needed. Online manual: https://geophilo.com/planx_mpyy_studio/
